状態: 初版（T-244、G-17）。確認日: 2026-11-12。
**これは法的な助言ではない。** 規約の読み取りと、断定できない点の整理だけである。公開前に、各社の最新の規約を人が読んで判断すること。

## 前提（IdleShift の使い方）

- IdleShift は各社の **正規のアプリの正規の機能（MCP のツール呼び出し）** だけを使う。AI アプリにログインするのは人で、IdleShift は認証情報・トークン・クッキーに触れない。
- AI が IdleShift のツール `next` を呼んで、仕事が来るまで最長1時間待つ。仕事が来たら、AI はそのアプリの中で作業する。
- 各社のサービスへの通信は、すべて各社のアプリが行う。IdleShift 自身はネットワークに通信しない。
- CLI 起動アダプター（`src/adapters.mjs`）は **既定で無効**。人が有効にしたときだけ、各社の CLI（Claude Code の `claude -p`、Codex の `codex exec`、Antigravity の `agy`）を、その CLI のログインと権限設定のまま起動する。
- 1つのアカウントを複数の人で共有させる機能も、使用枠を他人に再販する機能も無い。

## 1. Anthropic（Claude、Claude Code）

一次情報:
- Consumer Terms of Service（有効日 2025-10-08）https://www.anthropic.com/legal/consumer-terms （2026-11-12 取得）
- Help Center「Using Claude Code with your Pro or Max plan」https://support.claude.com/en/articles/11145838-using-claude-code-with-your-pro-or-max-plan （2026-11-12 取得）

要旨:
- 第3条（7）: サービスに「自動化された、または人間でない手段（ボット、スクリプトなど）」でアクセスすることを禁じる。ただし、Anthropic の API キーを使う場合と、Anthropic が明示的に許可した場合は除く。
- 第2条: ログイン情報や認証情報を他人と共有すること、アカウントを他人に使わせることを禁じる。
- 第3条（2）: サービスと競合する製品やサービスの開発を禁じる。
- 第12条: 規約違反と判断した場合、予告なく停止できる。
- Help Center: Pro・Max の使用量は5時間ごとの枠と週ごとの枠で、Claude と Claude Code で共有される。自動化や長時間の利用を禁じる記述は、この記事には無い。

評価:
- 人がアプリを開き、AI が MCP ツールで待機・作業する使い方は、Claude Code（エージェントとして長く作業する製品）と MCP（Anthropic が提供する機能）の通常の使い方の範囲と考えられる。ただし、**人が席を外したまま何時間も連続で動かす使い方が、第3条（7）の「人間でない手段によるアクセス」に当たらないかは、規約の文言からは断定できない（要確認）**。
- CLI アダプター（`claude -p` の自動起動）は、スクリプトがサービスへのアクセスを始める形になるので、第3条（7）との関係はより強く **要確認**。サブスクではなく API キー（`ANTHROPIC_API_KEY`）で使えば、この条項の例外に当たる。
- IdleShift はアカウントの共有や再販をさせないので、第2条と第3条（2）とは衝突しないと考えられる。
