- この1時間、どの参加者も仕事を引き受けていない（cycles の増分 0、イベント 0 件）。使用量の変化は待機だけによるもの、と考えられる。ただし次の点に注意。

- 5時間枠は時間の経過で古い使用分が外れるので、減り方が実際の消費より小さく見えることがある。
- 1回だけの測定。

## 判定（plan.md の基準）

- 実証済みの条件は「学習後に1時間あたり2回以下の呼び出し、かつ使用量の変化がそのアプリの最小単位以下」を **2回以上**。今回 Claude Code は保留3600秒(1時間に約1回)、Antigravity は使用量の変化が最小単位未満、Codex は1ポイント。
- **今回の分類: 条件付き**（1回の測定のみ。Claude は待機以外の応答と区別できない）。もう1回、誰も操作しない時間帯に同じ測定をして、同じ結果なら「実証済み」に上げられる。
- 宣伝で書ける範囲（現時点）: 「Plus/Pro の5時間枠で、3つのAIを1時間待機させた消費は、Codex 1ポイント・Antigravity 0ポイント(表示の最小単位未満)・Claude 2ポイント以下だった(1回の実測、2026-11-13)」。「消費ゼロ」とは書かない。
